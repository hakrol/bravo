# Blogginnlegg

Les `AGENTS.MD`, `PROJECT.MD` og `src/content/blog/README.md` fra prosjektroten. README er felleskilden for språk, SEO, data, komponenter, bilder og ferdigkontroll.

Velg én hovedtype etter spørsmålet leseren skal få svar på, og les den aktuelle skillen:

| Hovedintensjon | Skill |
| --- | --- |
| Hva tjener ett yrke? Også historikk og arbeidsmarked for yrket. | [blogg-yrkeslonn](../blogg-yrkeslonn/SKILL.md) |
| Hvem tjener mest av to eller noen få konkrete yrker? | [blogg-sammenligning](../blogg-sammenligning/SKILL.md) |
| Hvilke yrker eller grupper topper en liste? | [blogg-rangering](../blogg-rangering/SKILL.md) |
| Hva viser lønnsnivået eller utviklingen i Norge eller en større gruppe? | [blogg-lonnsoversikt](../blogg-lonnsoversikt/SKILL.md) |
| Hvordan bruker leseren lønnsinnsikt i en samtale eller forhandling? | [blogg-lonnsraad](../blogg-lonnsraad/SKILL.md) |

En sammenligningsseksjon i et yrkesinnlegg gjør ikke hele innlegget til en sammenligning. «Hva tjener elektrikere sammenlignet med andre byggfag?» er normalt yrkeslønn; «Elektriker eller rørlegger: hvem tjener mest?» er sammenligning. Ikke last alle type-skillene for ett innlegg.

Bruk [bloggbrief](../bloggbrief/SKILL.md) hvis brukeren bare ønsker en bestilling. Begrepsforklaringer som «Hva er medianlønn?» bruker [forklaringsinnlegg](../forklaringsinnlegg/SKILL.md). Aktuelle lønnsnyheter følger `skills/nyhetsartikler/SKILL.md`.

Bestillingen i samtalen er arbeidsgrunnlaget. Det finnes ingen temakø. Spør bare når manglende informasjon vesentlig endrer artikkelens hovedintensjon eller datagrunnlag.
